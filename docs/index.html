How it works, in plain language: for every game line and prop, the program takes every book’s price, strips out the book’s built-in margin, and finds the middle (median) fair price across all the books. When one book’s price is better than that fair price by at least 3%, it shows up here. Edge is how far the book’s price sits from the fair price. EV is the expected profit per $1 staked if the consensus is right. SOLID means a 5%+ edge; THIN means 3–5% — real, but inside the noise. The assumption every play rests on: the consensus is right. If the consensus is wrong, the edge is wrong, and a single prop can miss by a wide margin even when the math is right on average. This never places a bet for you.
Data refreshes once a day at 6:00 AM CT. A fresh run can also be started by hand from the repo’s Actions tab (workflow: Daily EV scan).
Method: consensus fair price across books (median, vig removed). Same approach Optimal uses — Covers and Optimal have no public API, so this program does not call them directly.
